# Coaching – One Page Template

A modern, responsive one-page website template for coaching institutes / tuition classes.  
Built with plain HTML, CSS and Bootstrap, it’s easy to customize for any education or training brand.

## Features

- **Hero carousel** with full-screen background images, overlay, CTA buttons and quick stats
- **Sticky navbar** with scroll-based background change, active link highlight & animated mobile hamburger
- **Offcanvas mobile menu** for a clean navigation experience on small screens
- **Courses section** with card-style layout for different programs and meta details
- **Campus & classroom gallery** with hover overlay text and image zoom effect
- **Social section** with prominent icons/links to all major platforms
- **Contact section**  
  - Institute details (address, phone, email, timings)  
  - Embedded Google Map  
  - Inquiry form with basic validation & success alert (demo)
- **Back-to-top button** that appears on scroll
- **Footer** with dynamic year and author credit

## Tech Stack

- HTML5, CSS3 (custom styles)
- [Bootstrap 5](https://getbootstrap.com/)
- [Font Awesome](https://fontawesome.com/) icons
- jQuery (for smooth scrolling, navbar scroll effect, form handling)

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. Replace placeholder text, images and contact details with your own content.

Feel free to fork and adapt this template for your own coaching institute or educational project.
